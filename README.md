### 🗺️ Карта навигации: Общая структура (Иерархия) всего проекта в целом по Github.

> <s>⚠️ Разработчики имеют возможность заложить свои пути, через динамическую маршрутизацию (позже).</s>

> ⚠️ Скачивать весь проект целиком НЕТ НЕОБХОДИМОСТИ, качаем только требуемые для работы компоненты/модули (это сэкономит место на диске).

<pre>
meta-platform/ ⚫ <-- Эта папка целиком обязательна к скачиванию! Без неё не будет ничего работать!
├── compilers/ 🔀 <-- Монтирование ветки в DTE!
│   ├── tcc (или gcc)/ <-- Для автоматизированной компиляции исходных кодов на языке C.
│   │                    : Си может быть получен в процессе транспиляции с мета-языка.
│   └── mlg/ <-- Для компиляции исходных кодов на языке Meta.
│
├── database/ ⚫
│   └── service-information/ <-- Служебная информация (без шифрования)
│
├── me.c 🔐   <-- Первая консольная версия, написанная на языке C.
├── me.cfg ⚫ <-- Конфигуратор (настройки) ME.
└── me.exe ⚫🟢⌨️ <--
                     - Мета-платформа, обязательна к скачиванию.
                     - Без неё будет невозможным запустить какое-либо ПО,
                     -  созданное её же собственными средствами.
                     - Исключение из этого правила является: режим компиляции с отвязкой от мета-платформы.
</pre>
